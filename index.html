1. ภาพรวมโครงการ Docs Clone (Project Overview)

ยินดีต้อนรับสู่ Docs Clone ส่วนหนึ่งของชุดโปรแกรม Workspace Clone Suite รองรับการพิมพ์เอกสารทางวิชาการ รายงาน และการนำเสนอในคลิกเดียว

  • แก้ไขเอกสารแบบ Rich Text: ปรับแต่งฟอนต์ สี ขนาด การจัดหน้า ตาราง และรายการตรวจสอบ
  • เปิดและบันทึกไฟล์ข้ามฟอร์แมต: รองรับทั้ง .docx, .pdf, .odt (OpenDocument), .doc, .txt, .html และ .md
  • โหมดนำเสนอทันที (Instant Presentation): แปลงหัวข้อเอกสารเป็นสไลด์โชว์พร้อมเลเซอร์พอยเตอร์ หรือโหมด Teleprompter

2. ตารางเปรียบเทียบการรองรับไฟล์ (Supported Formats)

คุณสามารถทดสอบกดเมนู ไฟล์ - ดาวน์โหลด หรือปุ่ม บันทึกไฟล์ มุมขวาบนเพื่อส่งออกเอกสารเป็นฟอร์แมตต่างๆ ได้ทันที:

นามสกุลไฟล์ ประเภทเอกสาร ความสามารถในการเปิด/บันทึก
.docx Microsoft Word (OOXML) เปิดอ่านและส่งออกไฟล์ Word มาตรฐาน
.odt OpenDocument Text (LibreOffice) เปิดอ่านและสร้างแพ็กเกจ XML มาตรฐาน OASIS
.pdf Portable Document Format สร้างไฟล์ PDF พร้อมแบ่งหน้ากระดาษ A4

3. การใช้งานโหมดนำเสนอ (Presentation Mode)

เมื่อกดปุ่ม "นำเสนอ" สีม่วงที่มุมขวาบน ระบบจะวิเคราะห์โครงสร้างเอกสารและแยกสไลด์ให้อัตโนมัติโดยยึดจาก:

  1. หัวเรื่องระดับ 1 (Heading 1) และหัวเรื่องระดับ 2 (Heading 2)
  2. เส้นคั่นแบ่งหน้ากระดาษ (Page Break หรือเส้นคั่นแนวนอน)
"เขียนเอกสารเสร็จปุ๊บ กดปุ่มนำเสนอได้ทันทีโดยไม่ต้องเสียเวลาทำสไลด์ซ้ำซ้อน พร้อมเลเซอร์พอยเตอร์ในตัว"
